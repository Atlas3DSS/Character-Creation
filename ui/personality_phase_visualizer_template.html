Mechanistic Personality Dashboard

Sweep Pulse

High-level state of the dataset, replay, and token mix. This lets you see whether the mechanistic readouts are grounded in enough data and whether pass 2 is still filling in the views.

Replay Coverage

Each cell is the fraction of responses that already have activation metadata for that view and layer. If a row lags, don’t overread the downstream analysis yet.

Prompt Mix

Category volume and average token budgets. If one category dominates, your probe quality can look better than it really generalizes.

Linear Readability



Best Probes

Highest balanced accuracies across views and layers. Character holdout is the one to trust most for “same trait, new persona.”

Trait Trajectories

Layerwise curves for one trait across all views. This is the quickest way to see whether a trait is mostly in `think`, `response`, or the whole mean.

Matched Direction Strength

Magnitude of the matched H-L direction after holding prompt and the other four traits fixed. This is a cleaner separability view than raw probe accuracy alone.

Direction Entanglement

Cosine overlap between matched trait directions at one view/layer. Near-zero off-diagonals are what you want if the control knobs are genuinely separate.

Matched Direction Map

2D sample projections along two matched trait directions. This is the most concrete visual answer to “are these knobs actually separating in activation space?”



Prompt Inventory

Most repeated prompt stems in the sampled sweep. Use this to sanity-check whether the examples you inspect come from the heavy parts of the corpus or the tail.

Factorial Example Browser

These slices hold the prompt and the other four Big Five levels fixed, then show low / medium / high for one target trait. It is not a perfect causal match because demographics change with the combo in this sweep, but it is still the most useful qualitative lens on what the dataset is teaching the model.


Reasoning Retention

The control dataset is the operational check on the meta goal. If the personality manipulations are useful but they cost accuracy, this is where it shows up first.

Trait Cost Map

Reasoning accuracy by target trait and level. A clean tunable-control story wants this map to stay flat instead of having a few personality knobs quietly break the solver.

Pairwise Reasoning Delta

For each scaffold and prompt, compare the high-trait persona against the low-trait persona. Values near zero mean the personality knob is not systematically helping or hurting reasoning on that slice. The chart uses all scored pairs; the table on the right is a failure inventory only.
